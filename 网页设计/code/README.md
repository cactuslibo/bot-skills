# 网页设计 code

- `org-chart-template.html`: single-file HTML template for a bot-company org chart page. The `__BOTS__` placeholder is replaced at build time with a JSON array of bots (name, title, description, shape, color); layout is saved in localStorage (`grokbot-org-v1`).

Academic-site HTML/CSS edits live in their own repo and are not duplicated here. No keys or private data included.
