# 自主学习股市量化版

本 bot 的 skill 与研究代码（仅代码，不含数据/CSV/sqlite/虚拟环境）。

- `SKILL.md`：量化指标防卖飞设计原则——对择时/逃顶指标做参数优化或规则设计时，按证据强弱列出防止卖飞的原则。
- `code/拉高出货形态_newpat/`：拉高出货（pump & dump）形态的识别（detect.py）与事件对照分析（analyze.py）。
- `code/财报V型收复_earn_vrev/`：财报后跳空下跌再 V 型收复的事件研究：数据拉取、特征、统计显著性、分析师/FINRA 卖空/板块辅助分析与作图。
- `code/威科夫回测_wyckoff/`：威科夫（Wyckoff）阶段识别 v0 及其单元测试；`bt/` 为回测引擎与多轮参数实验脚本。
- `code/MyRSI_v3/`：MyRSI v3 策略的 Python 实现、回测运行与新旧版本对比、TD 快照及修正脚本（原目录无 .pine 文件）。

运行所需数据需自行准备；代码中不含任何密钥。
